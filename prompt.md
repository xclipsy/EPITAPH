Tengo pensado un diseño para un programa de EPITAPH, se trata acerca de un modelo que esta analizando el visual por cada guardado automatico que se realiza, analiza la arquitectura del proyecto (tree, dependencias, modularizacion, codigo muerto etc...) Y va actualizando el README.md en cada uno de esos guardados automaticos y en caso que exista el archivo de requeriments.txt va añadiendo cada uno de los requerimientos necesarios para la ejecucion del codigo para de esa forma el trabajo en equipo pueda tener los cambios completos de los ultimos archivos, carpetas y cambios de como funciona, si requiere un nuevo comando de inicio y demas, todo funcionara dentro de un chat interactivo en consola donde se podria configurar los permisos del proyecto, si desea un suggestions.txt por cada autosave (analice el proyecto) y de recomendaciones sobre si es mejor utilizar otro framework o otras versione de ellas, sobre mover archivos a ciertas carpetas para ayudar a modularizar, etc...

Pero la funcion principal sea actualizar el readme.md.

El usuario al ejecutar el .py le pedira [LA PRIMERA VEZ] que funciones desea activar, readme.md auto escalable, requeriments auto escalable, y modificar ciertos archivos para generar conexiones adecuadamente o usar una forma diferente de funciones que pueda ser mas optima, y el modelo dentro del chat por cada cambio que va realizando lo va mostrando dentro del chat visual.

Todo funcionara por medio de terminal y puedes utilizar PRAXIA CLI [carpeta: /home/wuisino/Projects/praxia/]
